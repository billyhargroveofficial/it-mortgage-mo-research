# Фото с Авито

Пользователь смотрит каталог **фото первым**. Плохие вторые кадры = провал всего приложения.

## Что уже сломалось

1. С карточки поиска качали `0.jpg` нормального размера и `1–3.jpg` как **150×110 превью того же первого кадра**. Пользователь: «вторая такая же, хуёвое качество».
2. Фикс: открыть галерею объявления, брать только `extended-gallery/frame-img`, уникальные URL, **720–1280 px**.
3. Поздние пачки: `nophoto` / `nUrl: 0`. Скрипт делал `unlink` каталога, если saved=0 → **стёр ~49 уже скачанных обложек**.
4. Авито после этого отдавал **чужие предыдущие объявления** и пустую галерею. Повтор по стёртым id оставался nophoto.
5. В прод уехала первая ~50 карточек с нормальными 0–3.jpg; дальше часто одно фото или ноль.

Итог на 11.09 после всех прогонов: 62 дома с 4 фото, 92 с одним, 49 без. Не вычищать оставшиеся дырки без нового аккуратного прохода.

## Правило скачивания

- Один таб, канонический URL объявления, сверка id в URL.
- Клик в главное фото / кнопку галереи.
- Кадры только из `extended-gallery/frame-img` (или актуальный marker полной галереи — проверить snapshot'ом, не угадывать).
- Уникальность по URL кадра, не по индексу превью.
- Отбрасывать всё, что меньше ~400 px по короткой стороне, и явные `150×110`.
- Сохранять `catalog/public/photos/<avitoId>/{0,1,2,3}.jpg`.
- Если 0 файлов — **не удалять** уже лежащее. Логировать miss и идти дальше.
- Между объявлениями пауза; при пустой галерее reload + проверка id, не «скачать что дали».

`page.fetch(url, { saveAs })` — из контекста страницы, куки Авито на месте. Прямой Node-fetch без сессии часто ловит заглушку.

## Каталог: как показывать

Уже сделано, не откатывать без просьбы:

- передний план `object-fit: contain` — **не зарезать**;
- фон — **размытый дубль той же фотки**, не чёрные поля;
- карусель `translate3d`, clamp по краям, без wrap;
- прелоад остальных кадров, когда карточка в viewport + `rootMargin: 200px`;
- модалка: opacity + sheet translate, 320 ms на выход.

Поля `houses.json` про фото нет: наличие = файлы на диске. UI глотает 404 через `onError` и прячет слот.
