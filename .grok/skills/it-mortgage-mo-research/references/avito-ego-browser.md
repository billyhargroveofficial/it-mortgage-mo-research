# Добыча Авито через ego-browser

Сначала скилл `ego-browser`, затем этот файл. Это не Playwright. Нет `locator()` / `getByRole()`. Есть `page.evaluate`, `click` по `data-marker` / `loc=`, один TaskSpace.

Общая дисциплина карточек (резерв, цена, фото≠alt) — `avito-listing-research`. Здесь только то, что взорвалось на домах МО.

## Вкладки и память

Пользователь отдельно запретил кучу вкладок. Режим:

- 1 TaskSpace;
- 1 Page `p1`;
- search → detail → search тем же `goto`;
- промежуточный JSON на диск после пачки (heredoc убивает переменные).

## URL и фильтры

Категория продажа домов МО:

```
https://www.avito.ru/moskovskaya_oblast/doma_dachi_kottedzhi/prodam-ASgBAgICAUSUA9AQ
```

**Не собирать `f=` руками** с кавычками и JSON внутри — Авито выкидывает фильтры. Порядок:

1. открыть категорию;
2. выставить цену полями `data-marker="price-from/input"` / `price-to/input` (или текущими маркерами, их проверить snapshot'ом);
3. кликнуть чекбоксы типа дома / земли **через evaluate по `data-marker`**, не по старому `@ref`;
4. открыть сортировку и выбрать **Дешевле**;
5. забрать `page.info().url` как рабочий URL **этой сессии**;
6. перед каждой новой страницей проверить видимый лейбл сортировки.

### Сортировка — грабля, которую уже словили

| Что сделали | Что получили |
|---|---|
| `?s=2` | **Дороже**, не Дешевле |
| Выдача 8–9 млн с `s=2` | 1204 карточки, заголовок «Дороже» |
| `data-marker="sort/custom-option(1)"` | **Дешевле** |
| `sort/custom-option(101)` | не оно (проверить текст) |

Всегда читать видимый текст «Дешевле» / «Дороже» / «По дате». Не доверять `s=`.

`localPriority=0` встречался в URL — не считать его заменителем радиуса МКАД.

## Экстракция ленты

Маркеры, живые 11.09.2026:

- карточка: `[data-marker="item"]`
- id: `data-item-id` или хвост URL `_(\d+)`
- title: `[data-marker="item-title"]`
- цена: `[itemprop="price"]` content
- счётчик: `[data-marker="page-title/count"]`

Готовый evaluate: `scripts/extract-page.js`. Он вытаскивает km / land / year / area / plot / reserved / sponsored из текста карточки. Это **предварительно**. Землю и готовность подтверждать на детали.

Скролл: лента виртуальная. Скроллить, пока `n` карточек не стабилизируется. Спонсорские карточки ломают видимый порядок цен — ранг по извлечённой цене после дедупа.

Покрытие «Дешевле»: первая страница 9–15 млн = почти все по 9 млн. Для 10–15 ближе к МКАД — отдельные страницы/коридор, иначе таблица слепая.

Охват 11.09 (ориентир, не обещание полноты):

- 40 локаций, **2881** карточка 9–15 млн, детально **~300**, в ИЖС/ЛПХ таблицу **181**;
- 8–9 млн при фильтрах дом+построен+ИЖС/ЛПХ+≤50 км: **~1200** карточек, keepers **22**.

Фраза в отчёте: «обнаруженные в покрытых выдачах на момент проверки», не «все дома МО».

## Экстракция детали

`scripts/extract-detail.js`. Маркеры:

- title `item-view/title-info`
- price `item-view/item-price` + `itemprop="price"`
- params `item-view/item-params`
- id `item-view/item-id`
- date `item-view/item-date`
- description `item-view/item-description`
- seller `item-view/seller-info`

После `goto` **обязательно**: URL содержит ожидаемый numeric id. Авито уже подсовывал **чужое предыдущее объявление** и пустую галерею на фото-прогоне. 3 ретрая, потом `verification_failed`.

`waitForSelector` по хрупким селекторам **зависал**. Рабочий паттерн первой успешной пятидесятки фото: timeout-wait + `evaluate`, не вечный wait по галерее.

Reservation: только явный текст «Забронировано» / «Товар зарезервирован». Не `itemprop=availability`. На срезе резервов в выдаче не видели. Формулировка: «отметка о резерве не обнаружена».

## Чекбоксы и stale refs

После клика по фильтру snapshot `@N` мертв. Искать заново по `data-marker`. Уникальный селектор обязателен: `.card` в каталоге матчил 203 узла — для ego-browser это ошибка. Писать `.grid > .card:first-child` или `data-marker`.
