# DeepSeek Flash vision — отделить говно и рендеры

Задача пользователя: «отделить говно дома и рендеры от реальных пиздатых новых домов и добавить фильтры». Ключ где-то в конфигах, воркеров можно много.

## Ключ и API

- Ключ: `~/.config/deepseek.env` → `DEEPSEEK_API_KEY`. Также бывает в `~/.zshrc` для `dsclaude`. **chmod 600, не коммитить, не печатать.**
- Base: `https://api.deepseek.com`
- Модель: **`deepseek-flash`** (V4.1-Flash, native vision). Легаси `deepseek-v4-flash-vision-exp` режется сюда же.
- Картинки: JPEG/PNG/GIF/WebP, `image_url` + `data:image/jpeg;base64,...` или https.
- Thinking по умолчанию **включён**. Для классификации **выключать**: `"thinking": { "type": "disabled" }`.
- JSON: `"response_format": { "type": "json_object" }`.
- Concurrency Flash: **2500**. На 154 дома хватило **72** воркеров, **8.9 с, 0 фейлов**.

Не слать ключ в браузер и не класть в `catalog/src`.

## Что измеряли 11.09.2026 (idle, не пик)

Пик DeepSeek: пн–пт 09:00–12:00 и 14:00–18:00 **по Пекину**. Вне пика цена ×0.5.

Прайс Flash idle за 1M токенов: input miss **$0.15 / 1 元**, cache hit **$0.003 / 0.02 元**, output **$0.60 / 4 元**.

Калибровка на наших jpg (720×960, ~147 KB):

- промпт ≈ 380 input;
- 1 фото ≈ **550** input;
- ответ ≈ 45 output при thinking off.

154 дома с фото (92×1 + 62×4), 49 без фото скип. Факт после прогона:

- prompt 213052, hit 38272, miss 174780, out 8777;
- **~$0.032 / 0.21 元**.

Если забыть выключить thinking — output раздувается, всё равно < $0.50, но незачем.

`detail: high/original` оставляли: надо отличать CGI от фото. `low` (512²) дешевле, хуже по рендерам.

## Лейблы

| `look` | Смысл | UI-чип |
|---|---|---|
| `nice` | живое фото нового/свежего аккуратного дома, хочется смотреть | Топ |
| `ok` | живое фото обычной коробки, не развалюха | Обычные |
| `junk` | старый/убитый/дача/мусорный недострой | Говно |
| `render` | 3D/CGI, нет убедительных живых фото дома | Рендеры |
| `unknown` | нет фото, API не звали | Без фото |

Дополнительно: `media` = `photo|render|mixed|none`, `lookConfidence`, `lookWhy`.

`live` в UI = nice+ok (без говна, рендеров и пустых).

Срез после прогона: nice 39, ok 66, junk 39, render 10, unknown 49.

Проверка глазами: nice = современный барнхаус; junk = дача в плюще; render = ночной CGI с идеальным газоном. Пограничье: новая кирпичная коробка на песке может уехать в `nice` вместо `ok` — не руками править сотню, только если пользователь ткнёт.

## Как гонять

Скрипт: `catalog/scripts/classify-looks.py`

```bash
# ключ подхватит из ~/.config/deepseek.env
python3 catalog/scripts/classify-looks.py
# или
DS_WORKERS=72 python3 catalog/scripts/classify-looks.py
```

Пишет jsonl `catalog/scripts/look-results.jsonl` (резюмабельно). Потом смержить в `houses.json` тем же способом, что в срезе: по id, без фото → unknown.

Промпт зашит в скрипте. Не классифицировать по title («новый коттедж 2026») — только по картинкам.

## UI

Фильтры в `catalog/src/App.jsx`: чипы look счётчиками, дефолт **`nice`**. Бейджи на карточке: Топ / Рендер / Говно. В модалке `lookWhy`. Сорт «сначала топ».
