# IT-ипотека, дома в МО — ресёрч через ego-browser

Проектный скилл. Не дублирует общий `avito-listing-research`: тот про любой товар на Авито. Этот — про **готовый дом под госпрограмму IT-ипотеки в ближнем Подмосковье** и про каталог, который из этого получается.

Перед работой обязательно прочитай:

1. этот файл целиком;
2. `references/it-mortgage-rules.md` — условия программы на дату среза и что перепроверять;
3. `references/geography-and-filters.md` — регион, города, земля, цена, км;
4. `references/avito-ego-browser.md` — как реально добывать карточки;
5. скилл `ego-browser` (API, один TaskSpace, один таб);
6. скилл `avito-listing-research` (не доверять карточке, дедуп по ID, «Дешевле», reservation);
7. корневой `AGENTS.md` этого репо — каталог, деплой, фото, vision, грабли.

Не пиши в `~/.agents/skills/` и не пушь в billy-skills-hub. Скилл живёт только здесь.

## Цель

Найти **живые объявления готовых домов**, которые *могут* подойти под IT-ипотеку как объект (земля + тип дома + география + бюджет), а не подтвердить одобрение банка. Юрлицо/ИП-первый собственник на Авито часто **не видно** — это помечается, а не выдумывается.

Выход по умолчанию:

- JSON-артефакты в `research/` (и/или `~/.grok/tmp/avito-mo-houses/` для сырых дампов);
- таблица markdown по возрастанию цены;
- при просьбе — каталог `catalog/` + Netlify + Notion.

Не звонить, не писать продавцам, не бронировать, не светить телефоны.

## Фазы

### 0. Перепроверить программу, если дата сдвинулась

Условия IT-ипотеки меняются. Если сегодня не 11.09.2026 — сначала официальные источники из `references/it-mortgage-rules.md`. Не тащи лимиты 9/18 млн и «Москву нельзя» из памяти.

### 1. Доступ на Авито

Авито с домашнего Wi-Fi ловит **QRATOR 429/439** «проблема с IP». Нужен sing-box hy2, egress `91.201.114.192`. Если первая выдача — капча/блок: не плоди вкладки, reload той же, при необходимости `handOff` пользователю. Подробности VPN — скилл `singbox-vpn`, пароли туда не копировать.

Один TaskSpace на всю охоту. **Один таб** `p1` (пользователь явно просил не жечь RAM). Search и detail — `goto` в том же табе. `finish({ keep: [] })` только когда работа реально закончена.

Каждый heredoc — новый Node-процесс: переменные не живут. После каждой пачки пиши JSON на диск.

### 2. Собрать выдачу

Категория: **Дома, дачи, коттеджи / Продам**, регион **Московская область**.

Базовый путь (проверен 11.09.2026):

`https://www.avito.ru/moskovskaya_oblast/doma_dachi_kottedzhi/prodam-ASgBAgICAUSUA9AQ`

Фильтры — **только через UI Авито**, потом забрать уже переписанный URL:

- цена: `price-from/input` и `price-to/input`, не `pmin`/`pmax` вслепую и не самодельный `f=`;
- сортировка **Дешевле** = `data-marker="sort/custom-option(1)"`. Параметр `s=2` — это **Дороже**, не Дешевле;
- дом **построен** (не проект/недострой как основной тип);
- земля ИЖС и/или ЛПХ, если чекбоксы есть; всё равно верифицировать на карточке;
- после клика по чекбоксу **не использовать старый snapshot ref**.

Волны цены, которые уже оправдали себя:

1. 9–15 млн (основной каталог);
2. 8.0–8.5 млн (добор: 22 keepers);
3. ниже 8 млн — не тратить детальный проход, там СНТ/физлица/убитые дачи.

Не надеяться на city-slug `mytishchi` / `ivanteevka` / `krasnoznamensk` — 11.09 давали 0 карточек. Искать область + фильтр км/локации, либо рабочие слаги из `references/geography-and-filters.md`.

Скролл до стабилизации виртуализированной ленты. Карточки: `data-marker="item"`. Скрипт: `scripts/extract-page.js` через `page.evaluate`. Дедуп **по item id**, не по title.

Покрытие: не останавливаться на первой странице «Дешевле» — она забита девятимиллионниками. Для 10–15 млн ближе к МКАД нужна отдельная волна.

### 3. Детальная проверка финалистов

Тот же таб, пачки 5–10 URL. После `goto` сверить, что URL содержит ожидаемый id. Если Авито подсунул **чужое объявление** (это случалось на фото-прогоне) — retry до 3, иначе `verification_failed`, не приписывать данные.

Скрипт: `scripts/extract-detail.js`.

Отсев в каталог:

- не ИЖС и не ЛПХ (СНТ/ДНП/садоводство) → мимо;
- доля / комната / таунхаус-секция без участка → мимо;
- явный недострой-коробка без дома как продукта → мимо, либо `junk` если уже в пуле;
- Струнино и прочий Владимир/не-МО → мимо;
- ТиНАО / Москва → мимо;
- аукцион / «цена от» без цены дома → мимо;
- дубли одной коттеджной пачки (пример: Лосино-Петровский 8,49 млн / 108 м² / 2025) — оставить одного.

Юрлицо-первый собственник: если в карточке не доказано — поле `sellerKind: unknown`, в текст «на Авито не видно, перед банком проверять». Не врать, что объект «точно проходит IT-ипотеку».

### 4. Фото

См. `references/photo-pipeline.md`. Коротко: **только** `extended-gallery/frame-img` после открытия галереи, уникальные URL, 720–1280px. Никогда 150×110 превью. Не `unlink` каталог, если скачалось 0 файлов — так уже снесли ~49 обложек.

Складывать в `catalog/public/photos/<id>/{0,1,2,3}.jpg`.

### 5. Классификация вида

См. `references/vision-classify.md`. Скрипт: `catalog/scripts/classify-looks.py`. Модель `deepseek-flash`, thinking **выключен**, много воркеров (дефолт 72). Ключ: `~/.config/deepseek.env`, не коммитить.

Лейблы в `houses.json`: `look` = `nice|ok|junk|render|unknown`, плюс `media`, `lookConfidence`, `lookWhy`.

Без фото → `unknown`, в API не слать.

### 6. Каталог и выдача человеку

Схема дома, UI, деплой — `AGENTS.md`. Не переписывать визуал без просьбы: blurred duplicate background + `object-fit: contain` на переднем плане, карусель без wrap, модалка с картой.

По умолчанию фильтр каталога — **Топ (`nice`)**.

Notion — только если попросили обновить. Страница одна, не плодить дубли.

## Чего не делать

- Не хардкодить `f=` с кавычками в URL — Авито сбрасывает фильтры.
- Не считать `s=2` сортировкой «дешевле».
- Не открывать пачку вкладок.
- Не обещать, что конкретный дом одобрят по IT-ипотеке.
- Не класть этот скилл в user-scope.
- Не коммитить `DEEPSEEK_API_KEY` и VPN-секреты.
